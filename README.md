# Holo Kaleid

ポインターの動きを対称に映すホログラム万華鏡。

```bash
npm install
npm run dev
```

http://localhost:8080 を開く。ポインターや指で描く。スペースで止める、`H` で操作パネル、再生ボタンで音。

「瞑想」ボタンを押すと瞑想モードになります。アンビエント音楽が自動で流れ、万華鏡は手放しでゆっくりと（呼吸の周期に近い約11秒で光が満ち引きする速さで）描き続けます。操作パネルは消えるので、ヨガや瞑想のお供に画面を眺めるだけにできます。終了は画面下のボタンか `Esc`。

操作パネルの「瞑想タイマー」で時間（10/20/30/60分）を選んでおくと、残り時間が瞑想中のボタンに表示され、最後の1分で音楽と画面がゆっくりフェードアウトして自動で終わります。入眠用にもどうぞ。

カバー画像と package-lock はまだ入っていません。`npm install` で依存は入ります。
